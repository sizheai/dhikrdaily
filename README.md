# DhikrDaily

A beautiful Islamic dhikr (tasbih) counter app built with React and Vite.

## 🌙 Features

- **5 Preset Dhikr Types**: SubhanAllah, Alhamdulillah, Allahu Akbar, La ilaha illallah, Astaghfirullah
- **Custom Target**: Set any number for your personal dhikr goals
- **Progress Circle**: Visual indicator of your progress
- **Total Counter**: Tracks all your dhikr across sessions
- **Local Storage**: Your progress is saved automatically
- **Beautiful Islamic Design**: Dark theme with green accents
